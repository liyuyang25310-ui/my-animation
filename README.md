# 月相共鸣 · GPT 启动动画

受《鸣潮》优诺氛围启发的非官方前端视觉概念。采用原创 CSS 月相、薄荷绿科幻 HUD、漂浮粒子、声波、四阶段加载进度与淡出转场，无需图片素材或构建工具。

## 运行

在仓库目录执行：

```sh
python3 -m http.server 5173 --bind 0.0.0.0
```

在浏览器中打开此服务即可。也可直接打开 `index.html`。Google Fonts 为可选字体，无法联网时自动使用系统字体。

启动过程约 10 秒，随后显示就绪界面；点击「再次感受共鸣」重新播放。适配移动端、键盘操作和系统减少动态效果偏好。

文件：`index.html` 页面结构、`style.css` 视觉与响应式样式、`app.js` 加载状态与粒子动画。

这是前端演示，进度为模拟加载，不会发送聊天请求，也不包含 GPT API 集成或官方角色素材。
